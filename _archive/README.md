# Agent-HTML Archive

This directory keeps retired Agent-HTML materials for historical reference.

Archived content is not a current architecture source, workspace package, docs
route, product surface, navigation target, test target, build target, or agent
operating path.

Current artifact, block, pipeline, and host work should use Canvas docs under
`apps/docs/content/docs/canvas`, Canvas source under `.agent-html`, and current
packages under `packages/cli` and `packages/react`.

Archived code includes:

- `apps/agent-html-app`: retired app shell.
- `apps/agent-html-example`: retired standalone example app.
- `packages/agent-html`: retired `.ahtml` runtime package.
- `src-tauri`: retired desktop app backend.
