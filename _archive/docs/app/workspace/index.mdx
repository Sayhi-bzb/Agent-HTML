title: Workspace
description: Understand the main working surface for Agent-HTML projects and artifacts.
---

Workspace mode is the primary product surface for project-backed work.

`useWorkspaceController` owns projects, sections, open tabs, active tab state,
write capability, and document navigation guards.

## Workspace Owns

- project list loading
- section tab creation
- active project and section selection
- project and section create/rename/delete/duplicate actions
- tab close, select, and reorder behavior
- dirty-section navigation guards

## Boundary

Workspace composes Runtime output. Runtime parsing, validation, rendering, and
block hosting stay under Runtime docs.
