---
title: Projects and Tabs
description: How workspace projects and open work tabs keep context visible.
---

Projects contain sections. Workspace tabs represent open sections.

Tab ids use `section:<sectionId>`. Tab labels mirror section titles.

## Expected Behavior

- opening a section creates a tab if one is not already open
- selecting a tab changes the active section
- renaming a section updates its tab label
- deleting a project removes its section tabs
- deleting a section removes its tab
- closing the active tab selects the nearest remaining tab

Dirty sections block tab switches, tab closes, project edits, and section edits
until the current section is saved.
