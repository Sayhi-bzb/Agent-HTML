---
title: Block Hosting
description: Host responsibilities for block runtime state and editing affordances.
---

`AgentHtmlBlockRuntimeProvider` hosts block interaction state.

It does not infer blocks from UI or layout. Hosts receive paths for explicit
`Block` elements and pass drop or prompt actions back to source-editing code.

It owns:

- active block
- hovered block
- drop indicator
- block input popover
- drag overlay
- landing preview
- `onDropIntent`
- `onPromptSubmit`
