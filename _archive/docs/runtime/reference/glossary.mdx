---
title: Glossary
description: Short definitions for runtime documentation terms.
---

## Source

Agent-HTML text before it has been parsed into the runtime AST.

## AST

The structured document tree produced by parsing Agent-HTML source.

## Schema

The component registry, tags, attributes, defaults, validation, and prompt
grammar.

## Cell

The root Runtime source element. A cell contains layout.

## Block

The explicit human-agent collaboration boundary inside a cell layout.

## Layout

Runtime tags that arrange blocks at cell level or arrange content inside a
block, such as `Stack`, `Cluster`, and `Grid`.

## UI

Runtime tags that render semantic components, such as `Card`, `Table`,
`Button`, and `Badge`. UI belongs inside `Block`.

## Runtime UI

The React UI used to render validated Agent-HTML output.

## Host

The application boundary that embeds runtime output.
