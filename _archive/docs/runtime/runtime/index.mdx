---
title: Runtime
description: How validated Agent-HTML documents become rendered runtime UI.
---

Runtime owns rendering for validated Agent-HTML documents.

Main exports:

- `renderAgentHtml`
- `renderInteractiveAgentHtml`
- `AgentHtmlRuntimeTheme`
- `AgentHtmlRuntimeViewport`
- `AgentHtmlPromptComposer`
- agent event helpers
- block runtime provider

Runtime UI renders DSL output. It is not App `shared/ui`.
