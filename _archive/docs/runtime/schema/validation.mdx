---
title: Validation
description: How Agent-HTML validation checks parsed documents.
---

`validateAgentHtml` checks parsed AST against Schema.

Validation sits after parsing and before rendering.

The root element must be `Cell`. `Cell` can only contain layout. Layout outside
`Block` can only contain layout or `Block`. `Block` can contain layout or UI.
UI must be inside `Block`. `Block` cannot be nested inside another `Block`.

## Validation Should Check

- allowed tags
- allowed attributes
- required structure
- invalid child relationships
- unsupported values

Validation returns `AgentHtmlValidationError`.
