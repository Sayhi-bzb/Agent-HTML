---
title: Prompt Grammar
description: How schema data supports LLM-friendly Agent-HTML authoring.
---

Prompt grammar is generated from Schema for the component grammar sections. The
prompt document itself is a static template that carries contract notes,
defaults, examples, and forbidden constructs.

Public helpers:

- `buildAgentHtmlPromptDocument`
- `buildAgentHtmlPromptGrammar`

Prompt grammar should not describe behavior absent from registry, validation, or
runtime rendering.
