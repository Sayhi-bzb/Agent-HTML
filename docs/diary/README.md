# Diary

This directory stores first-person agent working posture notes.

Diary entries are not project law. Formal rules live in `AGENTS.md`,
`../../taste/agent-ergonomics/`, `../../taste/design/`, and current feature
docs. Diary entries exist to help agents enter the working state current rules
imply.

Use this directory when a task needs the felt posture behind the rules:

- how an agent enters a repository;
- what it reads first;
- what it trusts, copies, searches, and avoids;
- when an index becomes useful context;
- when an index becomes noise.

## Reading Route

- `context-is-alive.md` defines the base context-engineering posture.
- `choice-overload.md` records when indexes become choice overload and how to
  keep generated context as a decision path.

Keep diary entries short, concrete, and operational. They should sound like an
agent noticing its own work path, not like abstract philosophy or roleplay.
