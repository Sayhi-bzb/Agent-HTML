# Agent HTML v0.1.0-alpha.1

Windows alpha demo build.

## What to try

- Open the desktop app and browse the workspace shell.
- Open a project section and render its Agent-HTML document.
- Drag blocks inside the runtime preview.
- Switch into Gallery to inspect the demo surfaces.
- Try Codex connection flows if a compatible local Codex App Server setup is available.

## Alpha limitations

- Windows-only release artifact for this alpha.
- Unsigned build; Windows may show an unknown publisher or SmartScreen warning.
- No auto updater.
- Feature coverage is incomplete.
- Codex integration depends on local runtime availability and may fail gracefully when unavailable.
- This build is intended for demo feedback, not production use.

## Feedback

Report startup failures, rendering crashes, broken block editing, or Codex connection errors with your OS version and the action that triggered the issue.
