# L0 Raw Values

L0 is the raw-value inventory under the Canvas semantic stack.

L0 values do not carry UI role semantics by themselves. They are the raw
materials later wrapped by named tokens, public classes, semantic roles, or
components.

```text
L0 = unsemantic raw values
```

This file only answers:

- what raw value categories exist;
- which values are currently observed;
- where those values currently appear.

Promotion rules live in `todo/semantic-pyramid.md`.
Token mappings live in `todo/L0-to-L1.md`.
