# Design Standards

This directory is the current Canvas taste route.

Read [`DESIGN.md`](./DESIGN.md) for product feel, visual judgment, component
judgment, layout judgment, and review checks. Use Canvas docs,
`agent-html/AGENTS.md`, `agent-html/styles/README.md`, and
`agent-html/components/README.md` for implementation law.

Read [`host/`](./host/) for Canvas host scenario taste: sidebar views, host
chrome, search, settings, gallery controls, theme controls, dense rows, and host
UI adapter consumption.

Historical design material remains in `_archive/design` for comparison only.
Do not treat the archive copy as current guidance.
