---
title: Workspace
description: Understand the main working surface for Agent-HTML projects and artifacts.
---

Workspace mode is the primary product surface for project-backed work.

It keeps the shell stable while the active work context changes. The header
tracks open contexts, the sidebar supports navigation, and the content well hosts
the current artifact or project surface.

## Workspace Is For

- navigating project-backed work
- switching between open tabs
- reviewing generated artifacts
- continuing a result through feedback and revision

## Workspace Is Not For

- editing runtime schema rules
- authoring preview-only gallery scenes
- replacing the runtime integration API
