---
title: Projects and Tabs
description: How workspace projects and open work tabs keep context visible.
---

Projects organize work. Tabs keep active contexts close at hand.

The header tab rail represents open workspace contexts. It should help users
return to recent work without turning navigation into a separate page family.

## Expected Behavior

- tabs represent open work contexts
- sidebar navigation stays project-oriented
- the active tab controls the main content well
- switching tabs preserves the operating shell

The goal is orientation during longer sessions, not a document browser with
unrelated frames.
