Start in the App docs when your goal is to use Agent-HTML rather than extend it.

## Basic Flow

1. Open a project-backed workspace.
2. Select or create the work context you want to inspect.
3. Review the artifact in the main surface.
4. Use the shell navigation to move between open contexts.
5. Continue the work by giving feedback against the visible artifact structure.

The app is designed to keep context visible while the active surface changes. The
header, sidebar, and content well remain stable so you can move between work
without relearning the frame.
