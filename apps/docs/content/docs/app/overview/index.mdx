The Agent-HTML app is the human-facing workspace for AI-native artifacts. It is
where generated work becomes something you can preview, review, compare, and
continue without losing the shape of the result inside a chat transcript.

The app is organized around one durable operating shell:

- **Workspace** is for project-backed work, open tabs, artifact review, and
  continued iteration.
- **Gallery** is for inspecting design studies, preview scenes, and theme-focused
  system work.

The app docs focus on product usage. Runtime internals, DSL authoring, package
exports, and rendering contracts live under Runtime.

## When to Use App Docs

Use this section when you want to:

- understand the Agent-HTML product surface
- review or navigate generated artifacts
- work across projects and open contexts
- inspect gallery scenes and design studies

For implementation details, switch to Runtime.
