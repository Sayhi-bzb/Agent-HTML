title: Core Concepts
description: The basic product concepts behind Agent-HTML artifacts and the app shell.
---

Agent-HTML uses a few stable product concepts.

## Artifact

An artifact is a durable AI-generated result. It should preserve the structure of
the work: claims, evidence, comparisons, decisions, risks, and next steps.

## Workspace

The workspace is the primary work surface. It hosts project-backed contexts,
open tabs, review surfaces, and active artifact work.

## Preview

Preview is part of the work loop. Agent-HTML artifacts should be visible while
they are being reviewed and revised, not only after export.

## Review

Review means reading the artifact as a shared object. The goal is to make it easy
to scan, judge, point at a section, request a revision, and continue.

## Gallery

Gallery is a product mode for design studies and preview scenes. It is useful for
checking visual systems, not for authoring arbitrary websites.
