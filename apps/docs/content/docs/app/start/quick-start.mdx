Start in the App docs when your goal is to use Agent-HTML rather than extend it.

## Basic Flow

1. Start in Workspace.
2. Pick a project section from the sidebar.
3. Review the section in the content well.
4. Use header tabs to switch open sections.
5. Save before leaving a dirty section.

Workspace opens the first available project section on load. Navigation that
would leave a dirty section is guarded.
