title: Gallery
description: Understand the App gallery mode for design studies and preview scenes.
---

Gallery mode has three views: Theme, Components, and Pets.

`useGalleryController` owns the active view, theme draft, component filters, and
gallery sidebar content.

## View Map

- **Theme** edits app theme variables.
- **Components** browses enabled runtime component tags.
- **Pets** browses companion assets for workspace personalization.

Leaving Theme with unsaved changes opens a save/discard confirmation.
