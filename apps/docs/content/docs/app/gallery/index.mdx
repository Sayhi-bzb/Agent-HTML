---
title: Gallery
description: Understand the App gallery mode for design studies and preview scenes.
---

Gallery mode is a product surface for inspecting design studies, scene previews,
and theme-focused system work.

It uses the same operating shell as Workspace mode. The sidebar may become an
editor or filter surface, and the header tabs may represent gallery views, but
the shell identity remains stable.

## Gallery Is For

- theme and color studies
- component showcase review
- preview scene inspection
- design-system checks inside the app frame
