title: Theme Studies
description: How gallery theme studies help inspect color and surface decisions.
---

Theme edits use an app theme draft.

The controller resolves draft values into runtime-compatible color token values
and CSS variables.

Saved theme values flow through Applied App Theme. Gallery owns the draft;
Applied App Theme owns the saved state used by Workspace and secondary app
roots.

## Actions

- selecting a preset replaces the draft
- editing a variable updates the draft
- Apply saves and applies the draft
- leaving dirty Theme requires save or discard
