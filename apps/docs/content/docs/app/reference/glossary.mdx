---
title: Glossary
description: Short definitions for App documentation terms.
---

## Artifact

A durable AI-generated result that can be previewed, reviewed, shared, and
continued.

## Workspace

The default App mode for projects, sections, and section tabs.

## Gallery

The App mode for Theme, Components, and Pets gallery views.

## Pet

A companion surface around workspace activity.

## Runtime

The DSL pipeline and rendering system that turns Agent-HTML source into runtime
UI.
