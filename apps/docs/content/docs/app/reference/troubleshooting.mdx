Start troubleshooting from the surface where the issue appears.

## First Checks

- Navigation blocked: check dirty workspace section or dirty Theme draft.
- Wrong tab content: check `surfaceMode` and active tab id.
- Gallery view mismatch: check active Gallery view id.
- Pet window mismatch: check pet window state event payload.
- Runtime output mismatch: switch to Runtime docs.

Runtime parsing, validation, and rendering issues belong under Runtime.
