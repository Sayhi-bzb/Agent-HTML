---
title: States and Status
description: Common App states and how users should interpret them.
---

Current App state groups:

- `surfaceMode`: `workspace` or `gallery`
- workspace: active project, active section, active tab, dirty section
- gallery: active view, theme draft, dirty theme
- applied app theme: saved theme draft and runtime CSS variables
- color mode: `light`, `dark`, or `system`
- pet host: enabled state, presence, prompt draft state, thread picker state

State names should stay stable across docs and UI.
