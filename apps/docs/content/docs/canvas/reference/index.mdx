---

Canvas keeps artifact code, local resources, and host code separated.

## Artifact Imports

Artifact and example code may consume:

- `@agent-html/react`
- `../ui/*`
- `../hooks/*`
- `../lib/*`
- `../schema/*`
- `../data/*`
- `../assets/*`
- semantic token classes
- compact layout and type utilities such as `gap-4`, `p-4`, `text-sm`,
  `text-base`, `leading-snug`, `min-w-0`, `overflow-hidden`, and `truncate`

Artifact and example code must not consume:

- `apps/agent-html-app/src/*`
- `packages/cli/src/host/*`
- old runtime UI
- old render APIs
- `#agent-html-playground/*`
- raw palette classes such as `bg-blue-500`
- arbitrary value classes, decorative gradients, oversized typography,
  oversized radius, heavy shadows, custom fonts, or manual tracking
- raw common primitives when a local UI primitive exists
- `className` or `style` on `Artifact` or `Block`

## Host Imports

Host code may consume:

- host-local composition modules
- CLI prompt and API helpers
- `#agent-html-playground/ui/*`

Host code must not consume:

- `@/app/*`
- `apps/agent-html-app/src/*`
- old runtime UI
- old render APIs
- `@agent-html-playground/*`
- `#agent-html-playground/*` outside `#agent-html-playground/ui/*`
- a host-local visual primitive layer

## Review Checks

Confirm that `Artifact` keeps the fixed readable root container, `Block` stays
protocol-only, `.agent-html/ui/*` remains the visual primitive layer,
`.agent-html/styles.css` remains the CSS runtime entrypoint,
`.agent-html/styles/theme.css` remains the semantic token value layer, font and
radius values stay explicit tokens, and block content layout stays explicit in
artifact composition.
