Use the runtime when you need to transform Agent-HTML source into a validated,
renderable artifact.

## Minimal Flow

1. Start with an Agent-HTML source string.
2. Parse the source into the runtime AST.
3. Validate the AST against the schema rules.
4. Render the validated document through the runtime host.
5. Provide the host app's CSS token context and Tailwind scanning setup.
