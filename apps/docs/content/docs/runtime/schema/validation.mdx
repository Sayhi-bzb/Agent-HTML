---
title: Validation
description: How Agent-HTML validation checks parsed documents.
---

`validateAgentHtml` checks parsed AST against Schema.

Validation sits after parsing and before rendering.

The root element must be `Cell`. `Block` is a layout tag but cannot be nested
inside another `Block`.

## Validation Should Check

- allowed tags
- allowed attributes
- required structure
- invalid child relationships
- unsupported values

Validation returns `AgentHtmlValidationError`.
