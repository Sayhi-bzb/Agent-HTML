---
title: Styling and Tailwind
description: Styling requirements for applications that render Agent-HTML output.
---

Applications that render Agent-HTML must include the runtime package source in
their Tailwind scanning.

The runtime package stays neutral. It does not preload example presets or own an
application's full visual system.

Host applications should provide:

- Tailwind scanning for runtime UI source
- app-level CSS token context
- theme mappings that match the host surface
- stable container sizing for rendered artifacts
