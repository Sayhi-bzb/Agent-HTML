---
title: Integration
description: How to embed Agent-HTML runtime output in an application surface.
---

Runtime integration connects validated Agent-HTML source to a host application.

The host app provides the frame, CSS token context, Tailwind scanning setup, and
any surface-level orchestration. The runtime provides the DSL pipeline and
rendered output.

Keep host concerns and runtime semantics separate. App shell behavior should not
be encoded into the DSL runtime.
