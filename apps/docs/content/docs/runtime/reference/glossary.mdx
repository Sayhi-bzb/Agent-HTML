---
title: Glossary
description: Short definitions for runtime documentation terms.
---

## Source

Agent-HTML text before it has been parsed into the runtime AST.

## AST

The structured document tree produced by parsing Agent-HTML source.

## Schema

The component registry, tags, attributes, defaults, validation, and prompt
grammar.

## Runtime UI

The React UI used to render validated Agent-HTML output.

## Host

The application boundary that embeds runtime output.
