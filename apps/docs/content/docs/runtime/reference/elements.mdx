---
title: Elements
description: A high-level reference for Agent-HTML element families.
---

Element data comes from `agentHtmlComponentRegistry`.

Current layout tags:

- `Cell`
- `Block`
- `Section`
- `Stack`
- `Cluster`
- `Grid`

`Cell` is the root Runtime source element. Layout arranges blocks inside a
cell. `Block` is the explicit collaboration boundary. UI belongs inside a
block.

Use Schema docs for contract changes.
