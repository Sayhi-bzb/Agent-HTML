title: Elements
description: A high-level reference for Agent-HTML element families.
---

Element data comes from `agentHtmlComponentRegistry`.

Current layout tags:

- `Cell`
- `Block`
- `Section`
- `Stack`
- `Cluster`
- `Grid`

`Cell` is the root for spatial Runtime source. `Block` is the explicit
collaboration boundary inside a cell.

Use Schema docs for contract changes.
