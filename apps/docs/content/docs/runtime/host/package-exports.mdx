Use the narrowest public surface.

## Stable Runtime Contract

`@/agent-html` is the stable contract for DSL core and production runtime host APIs.

## Explicit Runtime Imports

`@/agent-html/runtime` exposes explicit runtime host imports.

## Advanced Block Internals

`@/agent-html/runtime/block` is for advanced block hosting.

## Source Support

`@/agent-html/source` supports source-analysis surfaces.
