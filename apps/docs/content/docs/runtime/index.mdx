# Runtime

Runtime preserves, validates, renders, and evolves AI-native artifacts from durable source files.

## Constitution

### Durable Source

Artifact state lives in durable source files, not in chat state or runtime memory.

### Semantic Contract

LLMs express meaning through stable tags, blocks, and attributes, not through ad hoc layout or styling.

### Block Composition

Artifacts are composed from addressable blocks that can be inserted, removed, reordered, and regenerated.

### Portable Inspection

Artifacts can be shared, reopened, validated, and inspected across hosts, runtime versions, and agent sessions.
