---
title: Layout Primitives
description: The layout elements used to structure Agent-HTML artifacts.
---

Layout primitives arrange content without turning Agent-HTML into a free-form
website builder.

Common layout roles include:

- `Page` for the document surface
- `Stack` for vertical structure
- `Cluster` for compact inline groups
- `Grid` for structured comparison or grouped content

Use layout to support scanning and comparison. Do not use it to create decorative
page compositions.
