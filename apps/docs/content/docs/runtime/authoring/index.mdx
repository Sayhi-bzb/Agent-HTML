---
title: Authoring
description: Principles for writing Agent-HTML source that is semantic and reviewable.
---

Agent-HTML authoring should express meaning before appearance.

The DSL should help agents produce stable artifacts that humans can scan, judge,
and revise. It should avoid fragile one-off layouts and decorative choices that
do not improve review.

## Authoring Goals

- preserve the structure of the work
- make assumptions and decisions visible
- keep similar content expressed consistently
- reduce low-value presentation decisions
