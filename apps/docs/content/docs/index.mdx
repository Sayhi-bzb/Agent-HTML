---

Agent-HTML turns agent output into durable, previewable artifacts.

Use **App** docs when you want to understand the product experience: workspace,
gallery, review flow, and day-to-day usage.

Use **Runtime** docs when you want to integrate or extend the Agent-HTML DSL:
authoring rules, parsing, validation, rendering, and host requirements.

Use **Canvas** docs when you want to work with the isolated React artifact
sandbox: `.agent-html`, local UI primitives, token consumption, and host
inspection.
